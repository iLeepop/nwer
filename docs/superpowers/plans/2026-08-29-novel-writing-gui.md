# 小说写作 GUI 应用实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 基于 GPUI 构建一款本地优先、以段落块为核心编辑单元，并为 AI 辅助写作预留能力的小说写作桌面应用。

**架构：** 应用采用“文件夹即项目”的本地存储模型，章节、段落和大纲均以 JSON 文件持久化。界面由顶部项目栏、左侧导航、中心编辑区、右侧 AI 面板和底部统计栏组成，业务状态、存储服务与 UI 组件分层组织。

**技术栈：** Rust 2024、GPUI、gpui-component、Serde/serde_json、UUID、Unicode 字符分类。

---

## 1. 产品范围

### 1.1 核心能力

- 管理多个本地小说项目。
- 使用可配置层级的目录树组织章节，默认最大深度为 3。
- 以段落块而非连续文档作为正文编辑单元。
- 管理角色、背景、场景、事件和杂项五类项目大纲。
- 实时显示本章及全书统计信息。
- 自动保存并支持菜单、快捷键手动保存。
- 提供章节名称过滤和跨章节正文搜索。
- 第一版预留默认折叠的 AI 面板，后续接入用户提供的 Agent library。

### 1.2 第一版不包含

- AI 对话、生成、改写等实际能力。
- 云同步与多人协作。
- 文件冲突合并和外部修改监控。
- 自动备份文件。
- 项目模板。
- 自定义大纲分类。
- 写作字数目标。

## 2. 整体界面

```text
┌────────────────────────────────────────────────────────────────────┐
│ [小说项目 ▾] [新建] [打开]             文件 编辑 视图 设置          │
├──────────────┬──────────────────────────────┬──────────────────────┤
│ [章节|大纲]   │ 当前章节标题                  │ AI 助手（默认折叠）   │
│ [搜索……]      ├──────────────────────────────┤                      │
│              │ 段落块                       │ 对话区域              │
│ 章节/大纲树   │ 段落块                       │                      │
│              │ [+ 插入段落]                 │ 输入框与发送按钮       │
├──────────────┴──────────────────────────────┴──────────────────────┤
│ 本章总字数｜汉字｜标点空格｜块数｜对话数｜全书总字数               │
└────────────────────────────────────────────────────────────────────┘
```

### 2.1 顶部项目栏

- 显示当前项目并提供最近项目下拉列表。
- 支持新建项目和打开已有项目文件夹。
- 项目名旁以圆点表示存在尚未落盘的数据。
- 提供文件、编辑、视图和设置菜单。

### 2.2 左侧导航

- 使用“章节 / 大纲”双 Tab。
- 章节 Tab 显示可展开的目录树。
- 大纲 Tab 按五类固定分类分组。
- 搜索框支持名称过滤和全文搜索模式。

### 2.3 中心区域

- 选中章节时显示章节标题及段落块编辑器。
- 选中大纲条目时显示 key-value 表单编辑器。
- 中心区域随左栏或 AI 面板折叠自动扩展。

### 2.4 右侧 AI 面板

- 第一版默认折叠。
- 展开后显示占位消息流、禁用的输入框和发送按钮。
- 后续以对话式交互为主，同时支持动作式续写、改写、扩写等操作。
- 用户可将选中段落块的文本和元数据一并作为 AI 上下文。

### 2.5 底部统计栏

- 实时显示本章总字数、汉字数、标点空格数、块数、对话块数和全书总字数。
- 不显示写作目标。

## 3. 项目与存储

### 3.1 应用配置

应用配置保存在平台配置目录下的 `nwer/config.json`：

```json
{
  "projects_root": "~/Documents/Novels",
  "recent_projects": [
    {
      "path": "~/Documents/Novels/示例小说",
      "title": "示例小说",
      "last_opened": "2026-08-29T09:00:00Z"
    }
  ],
  "max_recent": 10
}
```

- `projects_root` 是新建项目的默认根目录。
- 最近项目最多保存 10 条，按最后打开时间倒序排列。
- 从最近列表移除项目时不删除磁盘内容。

### 3.2 项目目录

```text
示例小说/
├── project.json
├── chapters/
│   ├── vol-001第一卷/
│   │   ├── part-001上篇/
│   │   │   ├── ch-001开篇.json
│   │   │   └── ch-002相遇.json
│   │   └── part-002下篇/
│   │       └── ch-001转折.json
│   └── vol-002第二卷/
│       └── ch-001新章.json
└── outline/
    ├── 角色/
    ├── 背景/
    ├── 场景/
    ├── 事件/
    └── 杂项/
```

章节目录遵循以下规则：

1. 应用将所有中间层统一视为目录，不赋予固定的“部、卷、章”语义。
2. 项目默认最大目录深度为 3，可在项目设置中修改。
3. 同一目录不能同时包含子目录和章节 JSON 文件。
4. 推荐使用 `vol-001标题`、`part-001标题`、`ch-001标题.json` 格式命名。
5. 移动或新建节点时必须先验证深度及目录/章节互斥规则。

### 3.3 项目元数据

`project.json`：

```json
{
  "schema_version": 1,
  "id": "0198f86d-55be-7000-8000-000000000001",
  "title": "示例小说",
  "created_at": "2026-08-29T08:00:00Z",
  "updated_at": "2026-08-29T09:00:00Z",
  "last_opened_chapter": "0198f86d-55be-7000-8000-000000000002",
  "total_word_count": 128403,
  "settings": {
    "max_depth": 3,
    "word_count_exclude_types": ["note", "scene_break"]
  },
  "ui_state": {
    "expanded_nodes": ["vol-001第一卷", "part-001上篇"],
    "sidebar_tab": "chapters",
    "ai_panel_open": false
  },
  "ai_context": {
    "style_guide": "第三人称有限视角，古风",
    "synopsis": "少年修仙成长史"
  }
}
```

`schema_version` 用于未来数据迁移。角色等结构化设定从 `outline/` 读取，不在 `project.json` 中重复存储。

### 3.4 章节模型

```json
{
  "schema_version": 1,
  "id": "0198f86d-55be-7000-8000-000000000002",
  "title": "第一章 开篇",
  "blocks": [
    {
      "id": "0198f86d-55be-7000-8000-000000000003",
      "type": "narration",
      "content": "他推开门，屋里的烛火轻轻摇曳。",
      "speaker": null,
      "meta": {
        "created_at": "2026-08-29T08:00:00Z",
        "updated_at": "2026-08-29T08:05:00Z",
        "note": ""
      }
    }
  ],
  "meta": {
    "status": "draft"
  }
}
```

段落块类型：

| 类型 | 用途 | 字数统计 |
|---|---|---|
| `narration` | 叙述与描写 | 统计 `content` |
| `dialogue` | 对话；可设置 `speaker` | 统计 `content`，不统计 `speaker` |
| `scene_break` | 场景分隔 | 不统计 |
| `note` | 作者备注 | 不统计 |

### 3.5 大纲模型

每个大纲 key 对应一个 JSON 文件，例如 `outline/角色/张三.json`：

```json
{
  "schema_version": 1,
  "id": "0198f86d-55be-7000-8000-000000000004",
  "key": "张三",
  "category": "角色",
  "fields": {
    "年龄": "18",
    "身份": "青云门外门弟子",
    "性格": "沉稳内敛"
  },
  "meta": {
    "created_at": "2026-08-29T08:00:00Z",
    "updated_at": "2026-08-29T08:05:00Z"
  }
}
```

- 分类固定为：`角色`、`背景`、`场景`、`事件`、`杂项`。
- 新建条目时输入名称并选择分类，字段集合初始为空。
- 字段名和值均可编辑，值支持多行文本。
- 文件名由条目 key 生成；重命名时同步原子移动文件。

## 4. 交互规格

### 4.1 段落块编辑

- 第一次单击块：选中。
- 再次单击已选中的块：进入编辑状态。
- 单击块外或按 `Esc`：结束编辑。
- 编辑状态按 `Enter`：在光标处分割文本，并在当前块之后新建 `narration` 块。
- 手动点击块间 `+`：先选择块类型，再插入。
- 对话块在正文上方显示可编辑的说话人标签。
- `Ctrl+↑`、`Ctrl+↓`：切换到前一个或后一个块。

第一版实现以下块级操作：

1. 编辑正文。
2. 通过手柄拖拽排序。
3. 在任意块间插入指定类型的新块。
4. 删除块并显示确认对话框。
5. 切换块类型；切换到 `dialogue` 时可填写 `speaker`。
6. 多选相邻块后合并；在光标位置按 `Enter` 拆分。

合并规则：

- 只允许合并连续选中的文本块。
- `scene_break` 不能与文本块合并。
- 合并后的类型采用首块类型。
- 多个块的正文使用换行连接。
- 若首块不是 `dialogue`，清除 `speaker`；否则保留首块 `speaker`。

### 4.2 章节导航

- 单击目录节点展开或折叠。
- 单击章节加载中心编辑区。
- 右键目录可新建子目录、章节、重命名和删除。
- 右键章节可重命名、复制和删除。
- 删除非空目录必须明确提示会删除其所有后代。
- 拖拽支持同目录排序和跨目录移动。
- 不满足深度或互斥规则的放置目标显示为不可用。
- 重新打开项目时恢复最后章节和已展开节点。

### 4.3 大纲编辑

- 左侧按固定分类显示条目。
- 中心区域以“字段名、字段值、删除按钮”的行表单呈现。
- 支持添加、删除、重命名和编辑字段。
- 与章节相同，修改后进行 500ms 防抖自动保存。

### 4.4 搜索

左侧搜索提供两种模式：

1. 名称过滤：匹配目录名、章节标题和大纲条目名称；保留匹配节点的祖先路径。
2. 全文搜索：扫描所有章节中可编辑文本块的 `content`，结果显示章节标题、块类型及命中摘要；点击结果后打开章节并定位、选中对应块。

`note` 默认参与全文搜索，`scene_break` 不参与。

### 4.5 字数统计

字符分类规则：

- 汉字：Unicode Han Script 字符。
- 标点空格：Unicode 标点、空白字符。
- 其他字符：拉丁字母、数字及其他非汉字、非标点字符。
- 总字数：汉字数 + 标点空格数 + 其他字符数。
- 只统计 `narration` 和 `dialogue` 的 `content`。
- `speaker`、`note` 和 `scene_break` 不计入正文统计。

底栏至少展示：

- 本章总字数。
- 汉字数。
- 标点空格数。
- 本章块数。
- 对话块数。
- 全书总字数。

当前章统计随内存内容实时变化；全书缓存使用“既有全书总数 - 当前章保存前总数 + 当前章新总数”增量更新。

### 4.6 保存

- 文本和字段输入采用 500ms 防抖保存。
- 增删、排序、类型切换和节点移动立即保存。
- 切换章节、切换项目和退出前同步保存。
- “文件 → 保存”和 `Cmd+S`（macOS）立即保存；其他平台映射为 `Ctrl+S`。
- 每次写入使用同目录临时文件，完成写入与同步后原子重命名。
- 第一版不创建 `.bak`。
- 保存失败时保留内存中的 dirty 状态，展示持久错误提示，并允许手动重试。

## 5. 菜单与快捷键

| 菜单 | 功能 |
|---|---|
| 文件 | 新建项目、打开项目、保存、退出 |
| 编辑 | 撤销、重做 |
| 视图 | 显示/隐藏左栏、显示/隐藏 AI 面板 |
| 设置 | 项目根目录、当前项目最大层级 |

第一版撤销/重做范围为当前文本输入组件；块增删、移动及类型切换暂不进入全局历史栈。

## 6. AI 扩展边界

第一版只定义数据边界，不依赖具体模型 SDK：

```rust
pub trait AiProvider {
    fn complete(&self, request: AiRequest) -> anyhow::Result<AiResponse>;
}

pub struct AiRequest {
    pub project_context: ProjectContext,
    pub chapter_context: ChapterContext,
    pub selected_blocks: Vec<Block>,
    pub outline_entries: Vec<OutlineEntry>,
    pub prompt: String,
    pub action: AiAction,
}

pub enum AiAction {
    Chat,
    Continue,
    Rewrite,
    Expand,
    GenerateDialogue,
    Summarize,
}
```

接入 Agent library 后，AI 结果必须先进入预览状态，由用户选择插入新块、替换选中块或放弃，不能无确认覆盖正文。

```text
    ├── mod.rs
```

文件职责：

- `models/*`：可序列化领域类型和不依赖 UI 的模型约束。
- `storage/*`：路径验证、目录规则、JSON 加载和原子写入。
- `services/*`：自动保存调度、全文搜索和字数统计。
- `app/state.rs`：当前项目、文档、选择、dirty 状态及 UI 状态协调。
- `ui/*`：GPUI 视图与用户事件，不直接实现磁盘规则。
- `ai/provider.rs`：未来 Agent library 与应用模型之间的适配边界。

## 9. 验证策略


GUI 功能还需进行手工验收：

9. 切换项目并确认先保存当前章节。
10. 展开和折叠 AI 面板并确认中心区域自适应。

## 10. 验收边界

第一版完成的定义：

- 用户可在固定根目录下创建、打开和切换小说项目。
- 章节树支持最多默认 3 层的灵活目录，并严格执行目录/章节互斥。
